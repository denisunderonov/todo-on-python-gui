# Задачник (Python + MySQL, GUI)

Короткое описание

Приложение — локальный "задачник" с графическим интерфейсом на Tkinter, которое сохраняет цели в базу данных MySQL.

Ключевые моменты

- Интерфейс: Tkinter (стандартная библиотека Python)
- База данных: MySQL (через модуль mysql-connector)
- Точка входа: `project.py`

Функционал

- Создание целей с категорией, описанием и датой
- Отметка цели как достигнутой
- Удаление целей
- Сохранение/загрузка данных в MySQL

Файлы в репозитории

- `project.py` — основной GUI-приложение и логика работы с БД
- `doapp.sql` — дамп/скрипт для создания структуры БД
- `ПЗ-приложение-задачник.docx`, прочие диаграммы — документация

Зависимости

- Python 3.8+ (рекомендуется)
- mysql-connector-python

Установка зависимостей (пример):

```bash
python -m pip install mysql-connector-python
```

Настройка базы данных

1. Создайте базу данных MySQL (например, `doapp`).
2. Выполните `doapp.sql` в вашей БД (через `mysql` или phpMyAdmin) для создания таблиц:

```bash
mysql -u root -p doapp < doapp.sql
```

3. По умолчанию `project.py` подключается к:

```python
host="localhost", user="root", database="doapp"
```

Если у вас другие креденшелы — отредактируйте `project.py`, изменив параметры в `mysql.connector.connect(...)`.

Запуск приложения

```bash
python project.py
```

Примечания по деплою / распространению

- Это десктопное приложение на Tkinter — его нельзя "задеплоить" на GitHub Pages или Vercel.
- Варианты распространения:
	- Для локального запуска: поставьте Python и MySQL на машине и запускайте `project.py`.
	- Для распространения пользователям без Python: соберите исполняемый файл с помощью PyInstaller
		```bash
		pip install pyinstaller
		pyinstaller --onefile project.py
		```
		Учтите, что MySQL всё равно нужен (или используйте встроенную SQLite-версию приложения).
	- Для миграции в веб: переписать часть GUI на Flask/Django и задеплоить на Render/Heroku/Cloud (потребуется рефакторинг и настройка БД).

Безопасность

- В коде учтите хранение паролей и доступ к БД: не хардкодьте креденшелы в коде в публичных репозиториях.
